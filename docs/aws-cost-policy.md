# 💸 AWS 과금 방지 협업 규칙 (팀 프로젝트용)

## 🧾 목적
팀 프로젝트 중 AWS를 사용할 때 프리 티어 한도를 초과하거나 불필요한 자원 사용으로 요금이 청구되는 것을 방지하기 위해 반드시 확인해야 할 항목을 정리합니다.

---

## ✅ 1. EC2 인스턴스 관련 확인 사항

| 체크 항목 | 설명 | 조치 방법 |

| 1.인스턴스 상태 확인 | 사용 후 중지하지 않은 인스턴스가 과금 원인 | 실습 후 반드시 **중지(Stop)** 할 것 |
| 2.인스턴스 타입 | 프리티어가 아닌 타입 선택 시 과금 발생 | `t2.micro` 타입 사용 (750시간/월 무료) |
| 3.중지 vs 종료 | 종료 시 모든 데이터 사라짐 / 중지 시 보존됨 | 평소엔 `중지`만, 정말 필요할 때만 `종료` |
| 4. 불필요한 인스턴스 삭제 | 실습 끝난 후 더 이상 안 쓰는 인스턴스 정리 | 팀원들과 상의 후 삭제 결정 |

---

## ✅ 2. EBS (Elastic Block Store) 확인 사항

| 체크 항목 | 설명 | 조치 방법 |

| 1. 볼륨 크기 초과 여부 | 프리 티어는 30GB까지 무료 (모든 인스턴스 합산) | 각 인스턴스 **8GB 이하로 제한** 권장 |
| 2. 사용 중지된 볼륨 | 인스턴스 삭제 후 남은 볼륨도 계속 과금됨 | EC2 > 볼륨 메뉴에서 불필요한 EBS 삭제 |

---

## ✅ 3. Elastic IP (EIP) 확인 사항

| 체크 항목 | 설명 | 조치 방법 |

| 1.인스턴스와 연결되지 않은 EIP | 연결 안 되어 있으면 시간당 과금 발생 | EC2 > 네트워크 > Elastic IP > **해제 및 삭제** |
| 2. EIP 재사용 여부 | 중지 시 자동 해제되지 않음 | 새 인스턴스에 연결하거나, 사용 안 할 경우 해제 필요 |

---

## ✅ 4. AMI 및 스냅샷 확인 사항

| 체크 항목 | 설명 | 조치 방법 |

| 1.오래된 AMI 이미지 | 저장 공간에 따라 비용 발생 | 실습 후 필요 없으면 삭제 |
| 2.스냅샷 과다 보유 | 한 개당 몇 GB씩 저장공간 차지 | 주기적으로 확인하여 정리 |

---

## ✅ 5. CloudWatch / SNS 관련 확인 사항

| 체크 항목 | 설명 | 조치 방법 |
|-----------|------|-----------|
| 1.로그 수집량 과다 | 기본 로그 외 과도한 수집 시 저장요금 발생 | 필수 로그만 수집 설정 |
| 2.오래된 경보/지표 | 유지 시 유료 옵션으로 전환 가능 | 실습 후 불필요한 경보 삭제 |
| 3.SNS 발송 로그 | 알림 서비스 사용 시 쌓이는 메시지 확인 필요 | SNS 구독 해제 or 주기적 관리 |

---

## ✅ 6. 기타 서비스 주의사항

| 체크 항목 | 설명 | 조치 방법 |

| 1.S3 사용량 | 대용량 파일 업로드 시 과금 | 프리티어 5GB 초과하지 않도록 주의 |
| 2.Lightsail / RDS / ECS | 별도 과금이 발생하는 서비스 | 사용 시 프리티어 해당 여부 확인 필수 |
| 3.활성 리소스 정리 | 모든 서비스에 활성 리소스 남아있는지 확인 | AWS 리소스 탐색기 또는 비용 탐색기 활용 |

---

## 🔐 SSH 및 보안 그룹 설정

| 체크 항목 | 설명 | 조치 방법 |

| 1.SSH 포트(22번) 관리 | 0.0.0.0/0로 열려 있으면 보안 위험 및 스캔 공격 대상 | **내 IP만 허용**하거나 실습 후 비활성화 |
| 2.필요 없는 인바운드 규칙 삭제 | 실습 끝나면 포트 닫기 | 보안 그룹에서 불필요한 포트 제거 |

## 📆 주차별 정리 체크리스트

### 🔁 매일 실습 후 (팀원 공통)
- [ ] 사용한 EC2 인스턴스 **중지**
- [ ] EIP 연결 여부 확인 / 불필요하면 해제
- [ ] 로그, 경보, 스냅샷 등 정리
- [ ] 팀 Notion or GitHub에 “정리 완료” 댓글 남기기

### 🧼 주말 정기 점검 (담당자 지정)
- [ ] 불필요한 인스턴스, 볼륨, EIP 삭제
- [ ] AMI, 스냅샷 삭제
- [ ] 비용 탐색기에서 예상 청구 금액 확인
